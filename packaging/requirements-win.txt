# CampusClear Windows 运行时依赖（离线安装用）
#
# 与 requirements.txt 的唯一实质差异：**用 CPU 版 onnxruntime 取代 onnxruntime-gpu**。
# 二者互斥，且 Windows 内网机普遍没有 NVIDIA 显卡 —— 装了 gpu 版反而会因为
# CUDA/TensorRT 提供器不可用而刷一堆告警，甚至在建会话时失败。
#
# imageio-ffmpeg 的作用是**提供一个随包分发的 ffmpeg 静态二进制**
# （Windows 没有 apt/brew，不能让用户自己去装 ffmpeg）。
# 本项目不调用它的 Python API，只在构建期把二进制拷到 bin/ffmpeg.exe。
#
# 生成离线 wheel 包：
#   pip download -r packaging/requirements-win.txt -d deploy/offline/wheels --only-binary=:all:
# 离线安装：
#   pip install --no-index --find-links=deploy/offline/wheels -r packaging/requirements-win.txt
